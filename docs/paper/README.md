Preamble requirements for the figure:

```latex
\usepackage{xcolor,pgfplots}
\usepgfplotslibrary{groupplots}
\pgfplotsset{compat=1.17}
```

The legend is placed below the group with `\ref*{lambdalegend}` — the starred
form, so hyperref does not paint it in the link colour. Axis limits are chosen
automatically with headroom; adjusting `ymin`/`ymax`/`ytick` per panel by hand
afterwards is expected and harmless, since the coordinates are what the tests
pin.
